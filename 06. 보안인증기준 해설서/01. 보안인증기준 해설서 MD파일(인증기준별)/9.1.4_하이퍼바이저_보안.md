# 9.1.4 하이퍼바이저 보안

## 인증기준

가상자원을 관리하는 하이퍼바이저의 기능 및 인터페이스에 대한 접근통제 방안을 마련하여야 한다. 또한 하이퍼바이저에 대한 소프트웨어 업데이트 및 보안패치를 최신으로 유지하여야 한다.

## 점검목적

클라우드 환경에서 하이퍼바이저(Hypervisor), 가상머신(VM), 컨테이너 등 가상화 계층을 안전하게 관리한다.

## 점검항목 해설

### 점검항목 1)

<!-- @block name=guidance requirement_no=1 cols=kind,text id=CM -->

| 구분 | 해설 |
|---|---|
| 본문 | 가상자원 관리를 위하여 하이퍼바이저에 대한 보호조치를 수립하여 적용하여야 한다. |
| 세부 | 하이퍼바이저에 대한 최신 업데이트 적용 |
| 세부 | 하이퍼바이저 관리기능에 대한 접근통제 |
| 세부 | ∙ 2-Factor 인증 적용, 원격관리의 경우 접근 IP 제한, 전용 관리단말 지정 등 |
| 세부 | ∙ 원격관리의 경우 통신 구간에 대한 보호대책 적용(암호통신 등) |
| 세부 | ∙ 접속 및 작업 로그 생성 및 보관 |
| 세부 | 비인가된 소프트웨어 설치 금지 |
| 세부 | 주기적인 하이퍼바이저 로그 분석 |
| 세부 | 서로 다른 이용자가 동일한 하이퍼바이저를 이용하는 멀티 테넌시(Multi-tenancy) 환경에서 이용자들의 가상머신(Virtual machine)을 서로 격리 |
| 본문 | 클라우드시스템 관리 인터페이스에 대한 접근을 제한하여야 한다. |
| 세부 | 방화벽을 사용한 제한된 콘솔 접근 |
| 세부 | 다중 요소 인증, IP 주소 필터링 등을 통한 접근제어 |
| 세부 | 하이퍼바이저 접근을 위한 관리망을 별도로 구성 |
| 세부 | 하이퍼바이저 원격 접속 관리 비활성화 또는 원격 접근이 필요 시에는 암호화된 통신 수단을 사용 |

### 점검항목 2)

<!-- @block name=guidance requirement_no=2 cols=kind,text id=CM2 -->

| 구분 | 해설 |
|---|---|
| 본문 | 관리자(운영자)에게 관리권한을 제공하는 경우 최소한의 관리기능만 사용할 수 있도록 하여야 한다. |
| 본문 | 관리행위에 대한 로그를 남기고 로그에 대한 주기적인 검토를 통해 위반 사항을 탐지할 수 있는 방안을 수립하여 적용하여야 한다. |

### 점검항목 3)

<!-- @block name=guidance requirement_no=3 cols=kind,text id=CM3 -->

| 구분 | 해설 |
|---|---|

| 본문 | 악성코드 감염 시에 대한 대응방안(격리 등)을 수립하여야 한다. |

## 부적합 사례

<!-- @block name=findings cols=text id=NC -->

| 부적합 사례 |
|---|
| 사례 1 : 하이퍼바이저를 운영하는 업무를 수행하지 않는 인력에 대해 하이퍼바이저에 대한 접근권한을 부여하는 경우 |
| 사례 2 : 하이퍼바이저에 대한 접속이력 로그를 저장하지 않으며, 주기적인 로그 분석을 수행하지 않은 경우 |
| 사례 3 : 하이퍼바이저에 허가받지 않은 소프트웨어가 설치된 경우 |
| 사례 4 : 하이퍼바이저에 대한 접근을 접근통제솔루션을 통해 통제하고 있으나 접근통제솔루션에 업무 필요성이 없는 사용자가 하이퍼바이저에 접근할 수 있도록 접근권한을 부여하고 있는 경우 |
| 사례 5 : 하이퍼바이저에 설치된 백신 프로그램에서 악성코드 감염 발생 시 대응하기 위한 대응방안이 마련되어 있지 않는 경우 |
| 사례 6 : 하이퍼바이저에 대한 주기적인 또는 최신 업데이트가 적용되지 않은 경우 |
| 사례 7 : 멀티 테넌트 환경에서 서로 다른 이용자의 가상머신 격리가 이루어지지 않은 경우 |
