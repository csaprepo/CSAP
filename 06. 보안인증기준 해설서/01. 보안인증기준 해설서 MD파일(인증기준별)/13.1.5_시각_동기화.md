# 13.1.5 시각 동기화

## 인증기준

로그기록의 정확성을 보장하고 법적인 자료로서 효력을 지니기 위해 클라우드시스템 시각을 공식 표준시각으로 정확하게 동기화하여야 한다. 또한 서비스 이용자에게 시각 정보 동기화 기능을 제공하여야 한다.

## 점검항목 해설

### 점검항목 1)

<!-- @block name=guidance requirement_no=1 cols=kind,text id=CM -->

| 구분 | 해설 |
|---|---|
| 본문 | 클라우드서비스 설계 시 감사증적(로그)의 생성일시를 동기화하기 위하여 표준시각을 동기화하는 기능을 제공하여야 한다. |
| 세부 | IaaS 클라우드서비스 제공자는 자체 시각 동기화 서버를 두고 Stratum 2 또는 3 수준을 이용하여 클라우드시스템 시간을 동기화 |
| 세부 | 서비스 제공자는 이용자에게 시각 정보 동기화 기능이 적용된 OS 이미지 제공 및 시각 동기화 안내 |
| 세부 | 운영체제에서 제공하는 NTP 서버 동기화 기능 활용 |
| 세부 | 클라우드시스템이 직접 NTP 서버와 동기화를 위해 NTP 서버를 설정하는 기능 제공 |
| 본문 | 로그기록의 정확성을 보장하고 법적인 자료로서 효력을 지니기 위해 각 클라우드시스템의 시각을 표준시각으로 동기화하여야 한다. |
| 세부 | 로그, 백업 관련 주요 클라우드시스템의 시각을 표준시각으로 동기화 |
| 세부 | 클라우드시스템의 시각이 표준시각으로 동기화되는지 주기적 점검 |

## 부적합 사례

<!-- @block name=findings cols=text id=NC -->

| 부적합 사례 |
|---|
| 사례 1 : 클라우드서비스 설계 시 표준시각을 동기화하는 기능 제공 관련 요구사항을 반영한 시스템 설계서 등 증적이 확인되지 않은 경우 |
| 사례 2 : 클라우드서비스 이용자에게 감사증적(로그)의 생성일시를 동기화하기 위한 표준 시각 동기화 기능을 제공하지 않는 경우 |
| 사례 3 : 클라우드서비스 제공자가 제공하는 VM 이미지에 시각 동기화 기능을 제공하지 않는 경우 |
| 사례 4 : 클라우드서비스 제공자가 운용하는 VM 서버가 정기적으로 시각 동기화하는 기능을 사용하지 않는 경우 |
