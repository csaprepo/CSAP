# 10.3.4 패스워드 관리

## 인증기준

법적 요구사항, 외부 위협요인 등을 고려하여 패스워드 복잡도 기준, 초기 패스워드 변경, 변경 주기 등 사용자 및 이용자 패스워드 관리 절차를 수립·이행하고 패스워드 관리 책임이 사용자 및 이용자에게 있음을 주지시켜야 한다. 특히 관리자 패스워드는 별도 보호대책을 수립하여 관리하고, 이용자 패스워드 관리절차는 공지하여야 한다.

| 공통 | 이용자 계정 및 패스워드 관리절차 관련 내용을 홈페이지 또는 메일 등을 통하여 이용자가 쉽게 확인하고 이해할 수 있도록 공지하고 있는가? |

## 점검목적

법적 요구사항과 위협 환경을 고려한 패스워드 관리 기준을 적용하여 사용자·이용자 계정의 보안을 강화하고, 특히 관리자 계정의 보호 수준을 높여 전체 시스템의 안전성을 확보한다.

## 점검항목 해설

### 점검항목 1)

<!-- @block name=guidance requirement_no=1 cols=kind,text id=CM -->

| 구분 | 해설 |
|---|---|
| 본문 | 사용자 및 이용자 패스워드 관리를 위한 관리절차를 수립하여 적용하여야 한다. |
| 세부 | 시스템 설계 시 패스워드 관리절차의 요구사항 적용 |
| 세부 | 패스워드를 별도 문서 또는 파일로 보관하는 경우 비밀등급으로 분류하여 비인가자의 접근통제 방안 수립 |
| 세부 | 패스워드 저장 기능(브라우저 자동 저장 등) 사용 제한 방안 수립 |
| 주의 | 패스워드 관리절차 예시 |
| 예시 | 문자(영문 대소문자), 숫자, 특수문자를 조합하는 패스워드 생성규칙 수립 |
| 예시 | 초기/임시 패스워드를 발급할 경우 클라우드서비스 최초 로그인 시 강제 변경 기능 제공 |
| 예시 | 패스워드는 이용자 정책에 따라 주기적으로 변경 (분기 1회 이상 권고, 동일 패스워드 재사용 금지) |
| 예시 | 연속된 자판 배열, 생일, 전화번호 등 추측하기 쉬운 개인 신상정보를 활용한 패스워드 사용 제한 |
| 예시 | 패스워드 처리(입력, 변경) 시 마스킹 처리 |
| 예시 | 클라우드시스템 침해사고가 발생하거나 패스워드의 노출 징후가 의심될 경우 즉시 패스워드 변경 |
| 예시 | 패스워드만 입력하는 자동 로그인은 금지 |
| 예시 | 패스워드 분실, 도용 우려 시 본인확인 등을 통한 안전한 재발급 절차 마련 등 |

### 점검항목 2)

<!-- @block name=guidance requirement_no=2 cols=kind,text id=CM2 -->

| 구분 | 해설 |
|---|---|
| 본문 | 관리자 패스워드는 일반 사용자 패스워드와 별도 관리하여야 한다. |
| 세부 | 예) 서버 시스템에 접속 가능한 일반 사용자 계정과 root 계정이 있는 경우 root 계정의 패스워드를 별도 안전하게 관리 (관리자 부재 또는 패스워드를 잊어버린 경우 확인 목적 등) |
| 세부 | 관리자 패스워드를 기록한 문서 또는 저장매체는 비밀에 준하여 관리 |
| 세부 | 내화금고 등 잠금장치로 비인가자의 접근통제 |

### 점검항목 3)

<!-- @block name=guidance requirement_no=3 cols=kind,text id=CM3 -->

| 구분 | 해설 |
|---|---|
| 본문 | 이용자에게 이용자 패스워드 관리에 대한 절차를 공지하여야 한다. |
| 예시 | 패스워드 생성 규칙 안내 (패스워드 복잡도, 길이 등) |
| 예시 | 연속 숫자, 생일, 전화번호 등 추측하기 쉬운 개인 신상정보를 이용한 패스워드 생성 제한 |
| 예시 | 주기적인 패스워드 변경 유도 |
| 예시 | 이용자 패스워드 분실·도난 시 안전한 재발급 절차(본인인증 등) |
| 예시 | 연속적인 로그인 실패 시에 대한 안내 |
| 예시 | 장기 미사용, 이용만료 등에 대한 안내 |
| 예시 | 패스워드 관리에 대한 책임 안내 등 |
| 본문 | 공지는 홈페이지 공지사항, 알림 메시지, 전자 우편 등을 이용할 수 있다. |

## 부적합 사례

<!-- @block name=findings cols=text id=NC -->

| 부적합 사례 |
|---|
| 사례 1 : 클라우드서비스 운영을 위한 클라우드시스템(VM, 하이퍼바이저, DBMS, Application(응용프로그램), 네트워크, 정보보호시스템 등)의 패스워드 관리절차를 수립하지 않는 경우 |
| 사례 2 : 내부 정책·지침에서 클라우드서비스 운영을 위한 클라우드시스템의 패스워드 생성규칙의 기준을 정하고 있으나, 일부 클라우드시스템에서 내부 정책·지침과 상이한 비밀번호를 사용하고 있는 경우 |
| 사례 3 : 내부 정책·지침에 패스워드 변경주기가 규정되어 있음에도 불구하고 패스워드를 변경하지 않고 그대로 사용하고 있는 경우 |
| 사례 4 : 운영자 또는 관리자 계정의 비밀번호가 브라우저 자동 저장 기능 등을 통해 노출될 가능성이 있는 경우 |
