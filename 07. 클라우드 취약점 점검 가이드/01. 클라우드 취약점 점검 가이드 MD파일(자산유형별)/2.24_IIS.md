## GUIDE-IIS-001 서비스 구동 점검

### 점검 정보

<!-- @block name=control keys=control_id,asset,category id=CK -->

|---|---|
| 점검코드 | GUIDE-IIS-001 |
| 플랫폼 | IIS |

### 항목 설명

IIS 서비스는 Web, FTP 등의 서비스를 제공해주는 유용한 서비스이지만 프로파일링, 서비스 거부, 불법적인 접근, 임의의 코드 실행, 정보 공개, 바이러스, 웜, 트로이 목마 등의 위협에 노출될 수 있다.

### 진단 기준

<!-- @block name=assessment_criteria keys=acceptable,vulnerable id=CR -->

| 판정 | 조건 |
|---|---|
| 양호 조건 | 불필요한 웹사이트가 구동 중이지 않은 경우 |
| 취약 조건 | 불필요한 웹사이트가 구동 중인 경우 |

### 진단 방법

<!-- @block name=check_steps method_no=1 cols=step,text id=MT -->

| 순서 | 절차 |
|---:|---|
| 1 | • 불필요한 웹 사이트 확인 |
| 2 | 1) Win + R → inermgr 명령어 입력 → 컴퓨터 이름 → 연결 → 사이트 |
| 3 | 2) 웹 사이트 목록 중 불필요한 사이트가 존재하는지 확인 |

### 조치 방법

<!-- @block name=remediation method_no=1 cols=step,text id=RM -->

| 순서 | 절차 |
|---:|---|
| 1 | • 불필요한 웹 사이트 중지 및 제거 |
| 2 | 1) Win + R → inetmgr 명령어 입력 → 컴퓨터 이름 → 연결 → 사이트 |
| 3 | 2) 불필요한 웹 사이트 중지 또는 제거 |
| 4 | ※ 불필요한 웹 사이트가 구동 중일 경우, 웹 사이트 중지/제거 권고 |

## GUIDE-IIS-003 CGI 실행 제한

### 점검 정보

<!-- @block name=control keys=control_id,asset,category id=CK3 -->

| 항목 | 내용 |
|---|---|
| 점검코드 | GUIDE-IIS-003 |
| 플랫폼 | IIS |
| 점검영역 | 보안 설정 |

### 항목 설명

CGI 스크립트는 정해진 디렉터리에서만 실행되도록 해야 한다. 게시판이나 자료실과 같이 업로드되는 파일이 저장되는 디렉터리에 CGI 스크립트가 실행 가능할 경우, 악의적인 파일을 업로드하고 이를 실행하여 시스템의 중요 정보가 유출될 수 있으며 침해 사고로 이어질 수 있다.

### 진단 기준

<!-- @block name=assessment_criteria keys=acceptable,vulnerable id=CR3 -->

| 판정 | 조건 |
|---|---|
| 양호 조건 | 지정하지 않은 CGI 모듈 허용 및 지정하지 않은 ISAPI 모듈 허용을 사용하지 않을 경우 |
| 취약 조건 | 지정하지 않은 CGI 모듈 허용 및 지정하지 않은 ISAPI 모듈 허용을 사용할 경우 |

### 진단 방법

<!-- @block name=check_steps method_no=1 cols=step,text id=MT3 -->

| 순서 | 절차 |
|---:|---|
| 1 | • IIS 관리자에서 확인 |
| 2 | 1) IIS 관리자 → 서버 선택 → ISAPI 및 CGI 제한 → 기능 열기 → 작업 → 기능 설정 편집 |
| 3 | 2) 지정하지 않은 CGI/ISAPI 모듈 허용 2개 모두 체크 해체되어 있는지 확인 |

<!-- @block name=check_steps method_no=2 cols=step,text id=MT3-2 -->

| 순서 | 절차 |
|---:|---|
| 1 | • IIS 관리자에서 확인 |
| 2 | 1) 설정 파일(C:\Windows\System32\inetsrv\config>applicationHost.config)에서 확인 “notListedlsapisAllowed”,“notListedCgisAllowed” 두 설정이 존재하지 않거나 false인지 확인 |
| 3 | ※ 두 설정값이 존재하지 않거나 false인 경우 양호함 |

### 조치 방법

<!-- @block name=remediation method_no=1 cols=step,text id=RM3 -->

| 3 | 2) 지정하지 않은 CGI/ISAPI 모듈 허용 2개 설정 모두 체크 해제 |

<!-- @block name=remediation method_no=1 cols=step,text id=RM6 -->

## GUIDE-IIS-007 미사용 스크립트 매핑 제거

### 점검 정보

<!-- @block name=control keys=control_id,asset,category id=CK7 -->

| 항목 | 내용 |
|---|---|
| 점검코드 | GUIDE-IIS-007 |
| 플랫폼 | IIS |
| 점검영역 | 보안 설정 |

### 항목 설명

사용하지 않는 스크립트 매핑은 보안에 위협이 될 수 있으므로 개발자와 협의하여 불필요한 매핑인지 확인한 후에 제거해야 한다. .asp나 .shtm 과 같은 확장자들은 특정 DLL 파일과 매핑되어 있어, 이러한 파일들에 대한 요청이 들어오면 해당 DLL에 의해 처리된다. 이러한 매핑 중에는 사용되지 않는 것들이 있어서 이를 제거해주는 것이 보안에 도움이 된다. ida , .idc, .idq, .printer, .htr, .htw 확장자는 Buffer overflow 공격 위험이 존재하므로 삭제를 권고한다.

### 진단 기준

<!-- @block name=assessment_criteria keys=acceptable,vulnerable id=CR7 -->

| 판정 | 조건 |
|---|---|
| 양호 조건 | 취약한 매핑(.htr .idc .stm .shtm .shtml .printer .htw .ida .idq)이 존재하지 않는 경우 |
| 취약 조건 | 취약한 매핑(.htr .idc .stm .shtm .shtml .printer .htw .ida .idq)이 존재하는 경우 |

## GUIDE-IIS-008 Exec 명령어 쉘 호출 진단

### 점검 정보

<!-- @block name=control keys=control_id,asset,category id=CK8 -->

| 항목 | 내용 |
|---|---|
| 점검코드 | GUIDE-IIS-008 |
| 플랫폼 | IIS |
| 점검영역 | 보안 설정 |

### 항목 설명

명령어가 Web 서버에서 임의의 명령을 호출하도록 사용될 수 있다. 임의의 명령을 호출하도록 설정되어 있다면 아래의 조치 방법에 따라서 설정을 변경하여 주는 것이 안전하다. HTML 페이지에서 웹 서버에 명령어 실행은 # exec 명령어를 통해 활용할 수 있다. 기본값으로 IIS 4.0에서는 사용할 수 있으나, IIS 5.0에서는 기본값으로 사용이 불가하다. 기본값은 서버 측의 허가되지 않은 실행 구의 동작을 방지하기 위해 변경되었다.

### 진단 기준

<!-- @block name=assessment_criteria keys=acceptable,vulnerable id=CR8 -->

| 판정 | 조건 |
|---|---|
| 양호 조건 | 해당 레지스트리 값이 0인 경우, 또는 IIS 5.0 이상에서 해당 레지스트리 값이 존재하지 않을 경우 |
| 취약 조건 | 해당 레지스트리 값이 1인 경우 |

### 진단 방법

<!-- @block name=check_steps method_no=1 cols=step,text id=MT8 -->

| 순서 | 절차 |
|---:|---|
| 1 | • 레지스트리 편집기에서 확인 |
| 2 | 1) 시작 → Win + R → regedit |
| 3 | 2) HKLM\SYSTEM\CuttentContorlSet\services\W3SVC\Parameters |
| 4 | 3) SSIEnableCmdDirective 값이 0으로 존재하는지 확인 |
| 5 | ※ defalut : 레지스트리 값이 존재하지 않음 (false로 설정됨) |
| 6 | ※ IIS v5.0 이상에서 레지스트리 값은 false |

### 조치 방법

<!-- @block name=remediation method_no=1 cols=step,text id=RM8 -->

| 순서 | 절차 |
|---:|---|
| 1 | • 레지스트리값 수정 |
| 2 | 1) 시작 → Win + R → regedit |
| 3 | 2) HKLM\SYSTEM\CuttentContorlSet\services\W3SVC\Parameters |
| 4 | 3) 우클릭 → DWORD → SSIEnableCmdDirective 레지스트리 값 0으로 추가 (레지스트리 값이 없는 경우 새로 생성) |

### 비고

※ 레지스트리 값 추가 후, 웹 서비스 정지 후 재시작 C:> net stop w3svc C:> net start w3svc
