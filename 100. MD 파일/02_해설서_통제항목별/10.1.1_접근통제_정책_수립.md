# 10.1.1 접근통제 정책 수립

## 인증기준

비인가자의 접근을 통제할 수 있도록 접근통제 영역 및 범위, 접근통제 규칙, 방법 등을 포함하여 접근통제 정책을 수립하여야 한다.

## 점검목적

접근통제 정책을 수립하여 비인가자의 접근을 예방하고 정보자산의 기밀성·무결성·가용성을 보호한다.

## 점검항목 해설

### 점검항목 1)

<!-- @block name=guidance requirement_no=1 cols=kind,text id=CM -->

| 구분 | 해설 |
|---|---|
| 본문 | 클라우드서비스 운영 서버, 개발 서버, 정보보호시스템, 이용자 데이터 등 중요정보자산에 대한 접근통제 정책을 수립·이행하여야 한다. |
| 세부 | 자산 유형별 접근통제 대상에 따라 접근권한과 책임, 승인 절차 명시 |
| 세부 | 주요 서버 또는 중요 데이터에 접근하는 경우 2-Factor 인증 고려 |
| 세부 | 시스템별 계정을 명확히 식별하고 안전한 접근수단 적용 |
| 세부 | 원격 접속시 전용선, 암호화 통신 또는 VPN 적용, 클라우드 콘솔 사용시 암호화 통신(https), 접근 IP 제한, 다중 인증 등을 적용 |
| 세부 | 클라우드서비스 보안 설정 기준(인증, 암호화, 세션 관리, 접근통제, 장기미사용 잠금 등) |
| 세부 | 서비스의 중요도에 따른 영역 간 접근통제 적용 |
| 본문 | 관리서버의 경우 보다 강력한 인증을 고려하여야 한다. |
| 본문 | 업무상 불가피하게 접근통제 정책을 벗어난 접근이 필요한 경우 접근시간, 접근위치 제한 등 추가적인 보완대책을 마련한 후 접근을 허용하여야 한다. |
| 세부 | 접근통제 정책 예외 시 책임자 승인 필요 |
| 세부 | 접근통제 정책 예외 시 책임자 승인, 허가기간 등의 이력 보관 |
| 본문 | 클라우드서비스 운영 서버에 접근 가능한 관리용 단말을 지정하고 무선을 통한 접근은 차단하여야 한다. |
| 세부 | 관리시스템 접근 가능한 단말을 관리용 단말로 지정하고 목록 관리 |
| 세부 | 접속 가능한 단말의 IP주소, MAC 주소 등으로 제한 |
| 본문 | DaaS의 경우 가상PC에 접근하는 접속 단말(내부망 PC 등)에 대해 IP 및 MAC 제한을 수행하여야 한다(IP/MAC 모두 통제 필요). |
| 세부 | 가상화 관리 솔루션의 기능을 활용하여 접속 단말 통제 가능 |

## 부적합 사례

<!-- @block name=findings cols=text id=NC -->

| 부적합 사례 |
|---|
| 사례 1 : 클라우드서비스를 운영하는 클라우드시스템(VM, 하이퍼바이저, DBMS, Application(응용프로그램), 네트워크, 정보보호시스템 등)에 대한 접근통제 절차를 수립하지 않는 경우 |
| 사례 2 : 클라우드서비스를 운영하는 클라우드시스템에 대한 접근통제 절차를 수립하였으나 수립된 접근통제 절차에 따라 접근통제를 수행하지 않는 경우 |
| 사례 3 : 업무용 모바일기기에 대한 허용 기준, 사용 범위, 승인 절차, 인증 방법 등에 대한 정책이 수립되어 있지 않은 경우 |
| 사례 4 : 클라우드시스템에 접근 가능한 관리용 단말을 지정하지 않고 있는 경우 |
| 사례 5 : 클라우드 REST API/CLI 등을 통한 우회 접근에 대한 통제 및 로그관리 정책이 수립되지 않은 경우 |
