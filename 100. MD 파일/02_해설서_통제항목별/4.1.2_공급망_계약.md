# 4.1.2 공급망 계약

## 인증기준

클라우드컴퓨팅서비스 범위 및 보안요구사항을 포함하는 공급망 계약을 체결하고 다자간 협약 시 책임을 개별 계약서에 각각 명시해야 하며, 해당 서비스에 관련된 모든 이해관계자에게 적용하여야 한다.

## 점검목적

공급자 및 제3자가 조직의 정보보호 요구사항을 충족하도록 보장하고, 공급망에서 발생할 수 있는 보안 리스크를 최소화한다.

## 점검항목 해설

### 점검항목 1)

<!-- @block name=guidance requirement_no=1 cols=kind,text id=CM -->

| 구분 | 해설 |
|---|---|
| 본문 | 공급망 계약 체결 시 서비스의 범위 및 수립된 보안요구사항을 계약서에 반영하여야 한다. |
| 세부 | 공급자가 제공하는 서비스의 범위 |
| 세부 | 공급자와 수요자의 역할과 책임 |
| 세부 | 공급자가 준수해야 하는 보안요구사항 |
| 세부 | 문제 발생 시 대책 및 법적 책임 등 |
| 본문 | 식별된 위험을 해결하기 위한 사항이 계약에 반영되어야 한다. |
| 본문 | 다자간 협약을 맺는 경우 각각의 역할 및 책임을 명시하여야 한다. |
| 세부 | 협약에 포함된 당사자들의 역할 및 책임을 개별 계약서마다 명시 |
| 주의 | 인프라사업자(IaaS 인증업체)와 계약 시 포함되는 내용 예시 |
| 예시 | 클라우드서비스 인프라 지원 및 관리 책임 |
| 예시 | 서비스 복원 및 복구에 대한 책임 |
| 예시 | 복원 및 복구 지원을 위한 서비스(소산 및 DR 등) 제공 |
| 예시 | 네트워크 모니터링 서비스 및 필요 시 보안관제 서비스 제공 |
| 예시 | 클라우드서비스 보호를 위한 정보보호시스템 제공 |
| 주의 | 클라우드서비스파트너(예: SW 개발·유지보수, 클라우드 관리 등)와 계약 시 포함되는 내용 예시 |
| 예시 | 기능적, 기술적 보안요구사항의 반영 여부 |
| 예시 | 개발 보안 가이드 준수 여부(시큐어 코딩 등) |
| 예시 | 테스트 시 보안요구사항 준수 여부 |
| 예시 | 개발 완료된 시스템에 대한 취약점 점검 등 수행 여부 |
| 예시 | 개발인력 대상 SW개발 보안교육 여부 |
| 본문 | 이용자의 보안요구사항은 계약서, 서비스수준협약서(SLA) 등에 반영을 검토하여야 한다. |
| 세부 | 계약서, 협약서 등에 명시된 요구사항은 클라우드서비스 제공자의 정보보호대책에 구현 |
| 세부 | • 이용자의 클라우드서비스에 대한 업무 연속성 유지, 안전성 유지 등의 원활한 운영에 대한 클라우드서비스 제공자의 책임 명시 |
| 세부 | • 클라우드서비스와 관련한 이용자 데이터의 물리적 위치 명시 |
| 세부 | SaaS 제공자를 포함하여 이용자가 보안요구사항의 준수여부에 대한 증거를 요구하는 경우 관련 자료를 제공 |
