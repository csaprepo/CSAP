# 3.2.3 변경 후 작업 검증

## 인증기준

클라우드컴퓨팅서비스에 사용된 자산(시설, 장비, 소프트웨어 등)의 변경 후에는 보안성 및 호환성 등에 대한 작업 검증을 수행하여야 한다.

## 점검목적

변경 이후 자산의 보안성·호환성·성능이 저하되지 않도록 검증하여 서비스 안정성과 신뢰성을 확보한다.

## 점검항목 해설

### 점검항목 1)

<!-- @block name=guidance requirement_no=1 cols=kind,text id=CM -->

| 구분 | 해설 |
|---|---|
| 본문 | 클라우드서비스 관련 정보자산 변경 후 서비스 영향도, 정상 동작 여부 확인 및 보안성, 호환성, 서비스 영향 등에 대한 작업 검증을 수행하여야 한다. |
| 세부 | 보안성 검토 : 정보자산 변경에 따른 보안정책 설정·변경 시 이상 유무 확인 |
| 세부 | 호환성 검토 : 정보자산 변경에 따른 타 정보자산과의 상호 호환성 이상 유무 확인 |
| 세부 | 서비스 영향 검토 : 정보자산 변경에 따른 서비스 성능 저하 여부 확인 |

## 부적합 사례

<!-- @block name=findings cols=text id=NC -->

| 부적합 사례 |
|---|
| 사례 1 : 클라우드서비스 관련 네트워크 구성을 변경하였으나, 서비스의 빠른 재개를 목적으로 충분한 호환성 검증 작업을 수행하지 않아 장애가 발생한 경우 |
| 사례 2 : 내부 규정에 자산변경에 따른 보안성, 호환성 등의 작업 검증 수행에 관한 내용이 마련되어 있지 않고 자산 변경 시 변경작업 결과보고서를 작성하였으나 결과보고서에 보안성, 호환성 등의 작업 검증을 수행했다는 내용을 확인할 수 없는 경우 |
| 사례 3 : 실제 운영 트래픽 환경에서의 특성 차이를 고려하지 않고, 개발·테스트 환경에서만 검증된 변경 사항을 운영환경에 적용하여, 서비스 중단의 위험이 발생할 가능성이 있는 경우 |
