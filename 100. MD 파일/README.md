## 🤖 기계 판독용 주석

각 파일에는 화면에는 보이지 않는 HTML 주석이 들어 있습니다. 스크립트나 RAG 파이프라인에서 문서와 표를 구조적으로 뽑아낼 때 씁니다.

```markdown
<!-- @meta doc_type=csap_standards_manual -->
<!-- @block name=profile cols=iaas,saas_standard,saas_lite,daas,low_grade,low_grade_saas id=AP -->
```

| 주석 | 의미 |
|------|------|
| `@meta doc_type=...` | 문서 종류 (`csap_standards_manual`, `csap_standards_manual_index`, `cloud_vulnerability_guide`, `cloud_vulnerability_guide_index` 등) |
| `@block name=...` | 바로 아래 표의 의미 (control, profile, requirements, evidence, findings, checklist 등) |
| `cols=` / `keys=` | 표의 열 이름(가로형 표) / 행 키(세로형 항목·내용 표) |
| `id=` | 블록 식별자 |
