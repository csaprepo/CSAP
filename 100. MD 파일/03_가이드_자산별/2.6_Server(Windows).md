## GUIDE-WSV-001 Administrator 계정 이름 바꾸기

### 점검 정보

<!-- @block name=control keys=control_id,asset,category id=CK -->

| 항목 | 내용 |
|---|---|
| 점검코드 | GUIDE-WSV-001 |
| 플랫폼 | Server(Windows) |
| 점검영역 | 계정 관리 |

### 항목 설명

일반적으로 관리자 계정을 Administrator로 설정한 경우 로그인 시도 실패 횟수의 제한이 없는 점을 이용해 악의적인 사용자가 패스워드 유추 공격을 끊임없이 시도할 수 있다. 공격자가 관리자 패스워드뿐만 아니라 계정 이름을 쉽게 유추하지 못하도록 Administrator 계정 이름을 변경해야 한다.

### 진단 기준

<!-- @block name=assessment_criteria keys=acceptable,vulnerable id=CR -->

| 판정 | 조건 |
|---|---|
| 양호 조건 | Administrator 외의 다른 계정 이름으로 변경하여 사용하는 경우 |
| 취약 조건 | Administrator 계정 이름을 변경하지 않고 사용하는 경우 |

### 진단 방법

<!-- @block name=check_steps method_no=1 cols=step,text id=MT -->

| 순서 | 절차 |
|---:|---|
| 1 | [CLI] |
| 2 | • 명령 프롬프트에서 확인 |
| 3 | 시작 → 실행 → cmd → net user 명령어 실행 후 Administrator 계정의 존재 유무 확인 |

<!-- @block name=check_steps method_no=2 cols=step,text id=MT-2 -->

| 순서 | 절차 |
|---:|---|
| 1 | [GUI] |
| 2 | • 로컬 보안 정책에서 확인 |
| 3 | 시작 → 프로그램 → 관리도구 → 로컬 보안 정책 → 로컬 정책 → 보안 옵션 → "계정: Administrator 계정 이름 바꾸기"의 값을 확인 |

### 조치 방법

## GUIDE-WSV-002 Guest 계정 상태

### 점검 정보

| 플랫폼 | Server(Windows) |
| 점검영역 | 계정 관리 |

### 항목 설명

Guest 계정은 시스템 임시 접근을 허용하는 취약한 계정으로써, 사용을 제한해야한다. 불특정 다수의 접근이 필요할 경우 Guest 계정이 아닌 일반 사용자 계정을 생성해 사용하도록 해야한다.

### 진단 기준

<!-- @block name=assessment_criteria keys=acceptable,vulnerable id=CR2 -->

| 판정 | 조건 |
|---|---|
| 양호 조건 | Guest 계정이 비활성화되어 있는 경우 |
| 취약 조건 | Guest 계정이 활성화되어 있는 경우 |

### 진단 방법

<!-- @block name=check_steps method_no=1 cols=step,text id=MT2 -->

### 항목 설명

| 취약 조건 | 불필요한 파일이 존재할 경우 |

### 항목 설명

| 취약 조건 | 계정 잠금 임계값이 5번 초과로 설정되어 있거나 설정되어 있지 않은 경우 |
